## Findings

### F-1: The reference-doc / AGENTS.md clause, appended "verbatim" to either host sentence, attaches to the `P2+` conjunct and states the exception backwards
**Severity:** P2
**Pre-ship recommended:** yes
**Where:** spec.md:21 (Scope row for `docs/spec-workflow-reference.md` / `AGENTS.md`)
**Convention violated:** The written register of the two tracked docs, and the spec's own instruction that the clause lands "verbatim" — which pins the words but not the joint. This is the placement residue of round-2 conventions/F-2, whose wording half is closed.
**Evidence:** Both host sentences put the `P2+` half last:
- `docs/spec-workflow-reference.md:81` — "… P0/P1 block shipping; P2+ are advisory."
- `AGENTS.md:101` — "… P0/P1 block shipping; P2+ do not. Reserve P0/P1 for genuinely load-bearing issues."

Spec:21 says "Line 81's 'P0/P1 block shipping' **and the same sentence at `AGENTS.md:101`** each gain this clause, verbatim: 'except that a finding the author routed to … never enters the gate'." Read at phrase level for line 81 and at sentence level for AGENTS.md, the spec is ambiguous; read the way an implementer appending a clause naturally will, `AGENTS.md:101` ships as "P0/P1 block shipping; **P2+ do not, except that** a finding the author routed to … never enters the gate" — an exception to *P2+ not blocking*, which is the exact opposite of the mechanism. Row 10's grep (`never enters the gate` → 1 per file) passes either way, so nothing catches it. This is the one sentence in two tracked, harness-neutral docs that a reader outside `/spec-cycle` will use to understand the gate.
**Suggested fix:** Pin the joint in spec:21 by giving the two target sentences in full, as em-dash asides on the `P0/P1` conjunct, e.g. reference doc `:81` → "P0/P1 block shipping — except that a finding the author routed to the spec's `## Deferred — follow-up required` section, under the scope ceiling, is not re-filed by the reviewers and so never enters the gate; P2+ are advisory."; `AGENTS.md:101` → the same aside before "; P2+ do not." Both remain single-line, per the Test-plan preamble at :190.
